# KMUTT ND69 — สรุปสิ่งที่เรียน

สรุปเนื้อหาที่เรียนในโครงการ **KMUTT Non-Degree 2026 (ND69)** ภาควิชาระบบควบคุมและเครื่องมือวัด มจธ. ตั้งแต่ Week 01–05 จัดทำเป็นงาน **Mini-Project #1**

## เขียนให้ใครอ่าน
**มือใหม่ที่ไม่เคยเรียนหลักสูตรนี้** — อ่านแล้วควรเข้าใจว่าแต่ละหลักสูตรเรียนอะไร ทำไมสำคัญ ต้องติดตั้งอะไร และเจอปัญหาอะไรบ่อย
ใช้ภาษาไทย ส่วนศัพท์เทคนิคคงเป็นภาษาอังกฤษเพื่อให้ค้นต่อได้ ศัพท์ที่ไม่คุ้นดูได้ใน [คำศัพท์](common/glossary.md)

## สารบัญ

| หลักสูตร | หัวข้อ | เริ่มอ่าน |
|---|---|---|
| **ND1** | นักพัฒนา Edge AI และ AIoT สมัยใหม่ — ESP32-S3, FreeRTOS, firmware ระดับผลิตภัณฑ์ | [nd1/](nd1/README.md) |
| **ND2** | นักพัฒนา GUI/HMI สำหรับ Mobile และ Edge — เว็บแอปคุยกับฮาร์ดแวร์ผ่าน Web Serial / Web Bluetooth | [nd2/](nd2/README.md) |
| **ND3** | นักพัฒนา AI และ Digital Twin เชิงอุตสาหกรรม — middleware แบบ ROS, warehouse simulation, digital twin | [nd3/](nd3/README.md) |
| ทุกหลักสูตร | Git, GitHub และ Markdown (Week 05) | [common/git-github-markdown.md](common/git-github-markdown.md) |

## วิธีอ่าน
- แต่ละบทมีโครงเดียวกัน: เรียนอะไร → ทำไมสำคัญ → แนวคิดหลัก (มีแผนภาพ) → ขั้นตอนลงมือ → ปัญหาที่พบบ่อย → คำศัพท์ → แหล่งอ้างอิง
- ด้านบนและล่างของทุกหน้ามีลิงก์ 🏠 หน้าหลัก / ⬅ ก่อนหน้า / ถัดไป ➡
- แผนภาพเขียนด้วย [Mermaid](https://mermaid.js.org/) ซึ่ง GitHub วาดให้อัตโนมัติ

- เนื้อหาเรียบเรียงจากบันทึกการเรียนของผู้เขียน และเอกสารของผู้สอน **ผศ.ดร.สันติ นุราช** ที่ [github.com/drsanti/kmutt-nd69](https://github.com/drsanti/kmutt-nd69) — repo นี้ **ลิงก์ไป** เอกสารต้นฉบับ ไม่ได้คัดลอกไฟล์หรือรูปของผู้สอนมา
